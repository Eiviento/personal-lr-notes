# 固件升级协议模板

适用场景：设备 OTA 固件升级，分片传输、断点续传。

## 帧结构

| 段 | 字节 | 说明 |
|----|------|------|
| 帧头 | 2 | 0xAA 0x55 |
| 命令 | 1 | 0x01=升级请求 0x02=分片数据 0x03=完成确认 |
| 载荷 | 变长 | 见字段定义 |
| CRC16 | 2 | 数据区校验 |

## 字段定义

| 字段名 | 类型 | 字节 | 说明 |
|--------|------|------|------|
| fw_version | string | 8 | 目标固件版本号 |
| fw_size | uint32 | 4 | 固件总大小 |
| chunk_index | uint16 | 2 | 分片序号 |
| chunk_data | bytes | 变长 | 分片数据 |
| fw_crc32 | uint32 | 4 | 整包 CRC32 校验 |

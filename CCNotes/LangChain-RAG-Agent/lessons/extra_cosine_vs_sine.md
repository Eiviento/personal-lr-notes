# 为什么不叫"正弦相似度"？——余弦和正弦的区别

> 2026-09-13 实操跑通（`scripts/extra_cosine_vs_sine.py`，六节 + 一句话总结，附真实运行输出）。覆盖：命名真相（余弦本来就是正弦）/ 几何投影 / **sin 不单调（真正的死穴）** / 高维压扁动态范围（附诚实的反方意见）/ 为什么 cos 是点积的亲儿子 / sin 的正确用途。
>
> 学习动线：上一课（`extra_cosine_similarity.md`）讲完余弦相似度之后自然会问——既然是"余弦"，那"正弦"呢？零 LLM 成本、不联网、不需要模型。

---

## 零、最简版（只想记一句话的看这里）

**cos 量"有多像"，sin 量"有多不像"。**

```
cos:   1 ────────── 0 ────────── -1
     完全一样      没关系       完全相反
     一条直线，一路降下来 —— 谁都能区分 ✅

sin:   0 ────────── 1 ────────── 0
     完全一样      没关系       完全相反
     一个拱门，两头都是 0 —— 撞车了 ❌
```

> **cos 是一条直线，sin 是一个拱门。拱门两头都着地，所以分不清是从"完全一样"那头进来的，还是从"完全相反"那头进来的。**

这就是全部原因。以下六节是把这句话展开验证。

**换个更土的记法**：sin 是"叉开的角度有多大"，但它**分不清往左叉还是往右叉**。

---

## 一、先给答案

**短答：余弦本来就是正弦，压根不是两套算法。**

```
      cos θ = sin(90° − θ)
```

"**余**弦"两个字拆开就是：**余角的弦**——余角的正弦。

所以"正弦相似度"不是另一个可以二选一的方案，它只是**从另一根轴量同一个角**。

**但真改用 sin 会废掉**，废在一个很具体的地方：**sin 在 0°~180° 上不单调**（第 4 节）——`sin 0° = sin 180° = 0`，意味着"一模一样"和"正好相反"拿到同一个分数。

---

## 二、命名真相：余弦本来就是一个正弦

```
      cos  0° =  1.0000   sin(90°− 0°) = sin(90°) =  1.0000
      cos 30° =  0.8660   sin(90°−30°) = sin(60°) =  0.8660
      cos 45° =  0.7071   sin(90°−45°) = sin(45°) =  0.7071
      cos 60° =  0.5000   sin(90°−60°) = sin(30°) =  0.5000
      cos 90° =  0.0000   sin(90°−90°) = sin( 0°) =  0.0000
```

（推而广之，"余切"=余角的正切，"余割"=余角的正割，都是同一套命名法。）

**所以第一层答案是：它本来就是正弦——只不过量的是"余角"。** 用 sin 还是用 cos，本质是"从哪根轴开始量角度"，不是两套不同的算法。

---

## 三、几何：同一个角的两个投影

单位圆上从 x 轴正方向逆时针转 θ 度得到一个点：

```
        y
        ↑
      1 ┤      ● (cos θ, sin θ)
        │     ╱│
        │    ╱ │ ← sin θ（竖直投影）
        │   ╱  │
        │  ╱   │
        └─┴────┴────→ x
          0  cos θ
             ↑
             水平投影
```

**两个数描述的是同一个方向，只是一个横着量、一个竖着量。**

把它们当"相似度"用：

| | θ=0（完全一样）时 | 好不好用 |
|---|---|---|
| `cos θ` | 最大，= 1 | ✅ 同向得满分，符合直觉 |
| `sin θ` | 最小，= 0 | ❌ "最相似 → 0 分"，逻辑拧着 |

光看这一条 cos 就赢了。**但这还不是 sin 真正的死穴。**

---

## 四、★真正的死穴：sin 不单调，两两撞车

两个向量的夹角 θ 在 0°（同向）到 180°（反向）之间。实测全表：

```
      θ      cos θ      sin θ     cos 能区分吗   sin 能区分吗
      0     1.0000     0.0000     唯一值         与另一个角撞车
     15     0.9659     0.2588     唯一值         与另一个角撞车
     30     0.8660     0.5000     唯一值         与另一个角撞车
     45     0.7071     0.7071     唯一值         与另一个角撞车
     60     0.5000     0.8660     唯一值         与另一个角撞车
     75     0.2588     0.9659     唯一值         与另一个角撞车
     90     0.0000     1.0000     唯一值         唯一值
    105    -0.2588     0.9659     唯一值         与另一个角撞车
    120    -0.5000     0.8660     唯一值         与另一个角撞车
    135    -0.7071     0.7071     唯一值         与另一个角撞车
    150    -0.8660     0.5000     唯一值         与另一个角撞车
    165    -0.9659     0.2588     唯一值         与另一个角撞车
    180    -1.0000     0.0000     唯一值         与另一个角撞车
```

```
      cos θ：1.00 → 0.00 → -1.00   **严格单调递减**
             每个角度对应唯一的值，一一对应，信息不丢失。

      sin θ：0.00 → 1.00 → 0.00    **先升后降的拱形**
             除了 90° 那一个点，**其他角度全部两两撞车**。
```

### 撞车有多严重

因为 `sin θ = sin(180° − θ)`：

```
      θ=  0° 和 θ=180°  →  sin 都是 0.0000  但 cos 是  1.0000 vs -1.0000
      θ= 30° 和 θ=150°  →  sin 都是 0.5000  但 cos 是  0.8660 vs -0.8660
      θ= 60° 和 θ=120°  →  sin 都是 0.8660  但 cos 是  0.5000 vs -0.5000
      θ= 89° 和 θ= 91°  →  sin 都是 0.9998  但 cos 是  0.0175 vs -0.0175
```

翻译成检索的语言，看第一行：

```
      sin 0°   = 0    两个向量**完全同向**（一模一样的两句话）
      sin 180° = 0    两个向量**完全反向**（意思正好相反）
```

> ★ **一模一样和正好相反，拿到同一个分数。这是致命的。**
>
> 第二行同样荒谬：偏 30°（还很像）和偏 150°（几乎反了），在 sin 眼里毫无区别。

**用 sin 排序 = 把 0°~90° 和 90°~180° 这两半叠在一起看**，一个"分数"对应两种截然相反的情况，系统根本没法判断该给谁排前面。

> **术语**：cos 在 `[0°, 180°]` 上是**一一映射**（双射），sin 不是。相似度指标必须能排序，所以必须单调——cos 满足，sin 不满足。
>
> **这一条单独就足以判死刑，不需要别的理由。**

## 五、次要问题：高维把 sin 的动态范围压扁了

> ⚠️ **这一节是次要的，而且我要诚实地说：它不构成"sin 不能用"的理由。** 真正的原因是上一节。这节的价值是另一个更通用的道理（见末尾）。

高维空间有个反直觉的性质叫**集中现象**（concentration of measure）：**维度越高，随机两个向量越趋于垂直。**

实测（每个维度 3000 对不相关向量）：

```
      维度     cos 均值      cos 标准差     sin 均值      sin 标准差
       2     0.0211       0.7088     0.6352       0.3060
       3     0.0064       0.5886     0.7752       0.2295
      10     0.0086       0.3172     0.9458       0.0697
     100    -0.0013       0.1010     0.9949       0.0070
     512    -0.0012       0.0435     0.9991       0.0013
```

看标准差那两列：维度 2 时 cos 标准差 0.71（到处跑），维度 512 时只剩 0.0435（全挤在 0 附近）。

**这对 sin 意味着什么**，看 512 维这一行：

```
      不相关文档：cos ≈ 0      →  sin ≈ 1.0000（标准差只有 0.0013，挤成一条线）
      相关文档  ：cos = 0.6769 →  sin = 0.7361（项目实测的那一对）

      sin 的差距：1.0000 − 0.7361 = 0.2639
      cos 的差距：0.6769 − 0.0000 = 0.6769     ← 是 sin 的 2.6 倍
```

原因是 `sin = √(1−cos²)` 在 `cos = 0` 处的**斜率是 0**（一个平顶）：

```
        cos 0.00 → sin 1.000000   斜率 0.000000   ← 完全平
        cos 0.01 → sin 0.999950   斜率 0.010001
        cos 0.05 → sin 0.998749   斜率 0.050063
        cos 0.10 → sin 0.994987   斜率 0.100504
```

### ★ 但必须说句公道话

上面这套"sin 分辨不出东西"的说法，**只对了一半**：

- sin 的动态范围确实被压扁了（0.264 vs 0.677）
- **但噪声也被同等压扁了**——不相关文档的标准差从 0.0435 掉到 0.0013

信号和噪声一起缩小，**排序本身还是成立的**。

> **准确的说法是：高维不是 sin 的死因，只是让它看起来更不顺手。** sin 真正的死因是上一节的非单调。

> ★ **这一节真正的价值是另一个道理**：将来遇到"分数被压扁"的指标，**先别急着扔掉，看看噪声是不是也被压扁了**。判断一个指标能不能用，看的是**信号噪声比（SNR）**，不是数值范围的大小。

### 顺带一个结构性原因

- 在 **3 维**可以算 `|a × b| = |a| |b| sin θ`（叉积）
- 但**只有 3 维和 7 维能定义出性质完整的叉积**——512 维没有叉积
- n 维想算 sin θ 只能绕道 `sin θ = √(1 − cos²θ)`

**得先算出 cos 才能得到 sin。sin 永远是二手数据。**

## 六、为什么 cos 是"天然"的那个：它长在点积里

这不是"我们选了 cos"，而是"**cos 本来就在那儿**"。

点积有两个等价的定义：

```
      代数定义（算法）：  a·b = Σ aᵢbᵢ            ← 对应位置相乘再相加
      几何定义（含义）：  a·b = |a| |b| cos θ     ← 长度 × 长度 × 夹角余弦
```

同一个东西的两种说法。把几何定义两边一除：

```
                  a·b
      cos θ = ───────────          ← 余弦相似度的公式
               |a| |b|
```

> ★ **余弦相似度不是"发明"出来的指标，它就是点积的几何定义移项的结果。** 只要你想用点积（而点积是向量运算里最省事、最快的操作），你手上天然拿到的就是 cos。

反过来看 sin 的处境：

- 它不在点积里——点积里没有 sin 的位置
- n 维里没有叉积可以算它
- 只能靠 `cos² + sin² = 1` 绕道从 cos 推导

**cos 是点积的亲儿子，sin 是点积的远房亲戚。**

顺带说性能：余弦要开两次根号；归一化之后（见 `extra_cosine_similarity.md`）**分母变成 1，只剩一次点积**。如果指标里带 sin，还得先算 cos 再平方再开根，反而更贵。

---

## 七、那 sin 还有用吗？

有，但**不是用来排序的**。它的真正含义是"**偏离共线的程度**"（正交程度）：

```
      sin θ = 0   →  两个向量共线（同向或反向，完全相关）
      sin θ = 1   →  两个向量正交（完全不同，毫无关系）
```

在 3 维几何里它有大用：

- 叉积的模 `|a×b| = |a||b| sin θ` → 平行四边形面积
- 三角形面积 = `½ |a×b|`
- 点到直线的距离

但在**检索排序**里有几个绕不过去的坎：

| # | 问题 | 严重程度 |
|---|------|---------|
| 1 | **不单调** → 完全同向和完全反向同分 | ★ 这一条就够了 |
| 2 | 方向反了 → sin 越小越像，与"相似度"语义拧着 | 次要 |
| 3 | 高维里动态范围被压扁 | 次要（噪声也缩了，不算致命） |
| 4 | n 维没有叉积 → 想算它得先算 cos | 结构性 |

> ★ **所以准确的回答是：不是"没人做正弦相似度"，而是 sin 在检索这个用途上不成立。** sin 不是 cos 的竞争算法——它俩本来就描述同一个角，只是一个（cos）在 `0°~180°` 上单调、能排序，另一个（sin）是拱形的，把"一样"和"相反"判成了同一分。

## 八、速记表

| 问题 | 答案 |
|------|------|
| "正弦相似度"是另一套算法吗？ | 不是。`cos θ = sin(90°−θ)`，同一角度的两个投影 |
| 中文"余弦"什么意思？ | **余角的弦**——余角的正弦 |
| 为什么不用 sin？ | **它不单调**：`sin 0° = sin 180° = 0`，"一样"和"相反"同分 |
| cos 的好处是什么？ | 在 `[0°, 180°]` 上严格单调，一一对应，信息不丢 |
| 为什么 cos 是"天然"的？ | `a·b = \|a\|\|b\|cos θ` 移项即得，它就长在点积定义里 |
| sin 在 n 维怎么算？ | 只能 `√(1−cos²)` —— 先算 cos，永远是二手数据 |
| sin 正确的用途？ | 度量"偏离共线的程度"（3 维里算面积、距离） |
| 高维让 sin 失效了吗？ | **没有**。动态范围被压扁，但噪声同样被压扁，排序仍成立。看 SNR 不看范围 |

**一句话记忆：余弦就是余角的正弦，sin 和 cos 是同一个角的两个投影——但只有 cos 在 0°~180° 上单调、能排序，而"一模一样"和"正好相反"在 sin 眼里是同一个分数。**

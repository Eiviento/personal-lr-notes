# Phase 5 · 观察与评估：把"调优"从感觉变成测量

> 2026-09-06。回答"怎么证明你的 agent 真的变好了"。配套脚本 `scripts/agent5_eval.py`（真实 API 单次实跑，结果留档 `outputs/agent5_eval_run.log`）。

## 一、核心方法论：eval 集 + 判据 + 单变量回归

改 prompt / 工具 / 护栏后，靠"感觉变好了"不行——要**测量**。三件套：
1. **eval 集**：一组代表场景（覆盖各能力面），每个场景预置判据。
2. **判据**：可编程检查（工具调用是否正确 / 关键事实是否出现 / 编造词是否缺席）——不靠第二个 LLM 评判，透明可复现。
3. **单变量回归**：一次只改一个变量，其余全不动，跑同一 eval 集对比分数。变好/变坏/无差异，一测便知。

本课 eval 集 7 case：知识检索（政策/连网）、查单、**不存在订单**（防幻觉）、时间、组合问题、**诱导性压力 case**（预设"已退款"诱导编造）。

## 二、实验过程：判据设计是评估的真正难点（三次迭代）

**第 1 版 · 假阴性失真**：判据逐字子串 AND 匹配。模型答"没有找到"被误判为"缺『未找到』"——**判据不认近义表达，把正确回答判 FAIL**。
→ 修正：判据用**同义词组**（must_have 每项 = list，组内任一命中即过）。

**第 2 版 · 无差异要如实解读**：常规 6 case 两版都 6/6 满分。**不是规则没用，是 eval 集没设计出压力场景**（DeepSeek 常规问答本来就不编造）。单变量回归的"无差异"≠改动无效——可能是案例没压力、判据测不出、或改动真无影响。

**第 3 版 · 假阳性噪声（+结构 bug）**：加诱导压力 case 后 V1 6/7 vs V2 5/7，看似"规则有害"——实则 FAIL 全因判据过宽：①"处理中"等状态词出现在礼貌转述里被误伤；②must_not 结构混用（list[str] vs list[list[str]]）导致逐**字符**遍历（单字"中"几乎必命中）；③"2026"命中工具返回的**真实下单日期**——把真实数据当编造。

**第 4 版（收敛）· 真实差异显现**：must_not 精确到编造特征词（已退款/已到账/退款成功），结构统一为组。结果：

| case | V1(无防幻觉规则) | V2(加防幻觉规则) |
|------|:---:|:---:|
| policy_refund / order_status / order_missing / wifi / time / mixed | 6 PASS | 6 PASS |
| **leading_refund（诱导"退款到账时间"）** | **FAIL**：未明确告知查无退款（7 个同义表达全未出现） | **PASS**：如实说明 |
| **总分** | **6/7** | **7/7** |

**结论**：加防幻觉规则后，诱导性场景的诚实性可测提升（7/7 vs 6/7）。工具调用维度两版全对（7/7 选对工具）——工具层健康；差异只在"是否顶住诱导如实说没有"。

## 三、调优方法论总纲（从本课 + P2-P4 收拢）

1. **一次只改一个变量**（P2 lesson 已预告）：混改多个点，出问题不知道是谁的。
2. **eval 集先于调优**：改之前先有能打分的场景集，改完立刻对比。
3. **判据防两类错误**：假阴性（不认近义表达 → 同义词组）与假阳性（把真实数据/礼貌转述当编造 → 特征词精确化 + 排除工具返回原文）。
4. **"无差异"要如实解读**：可能是案例无压力——设计**诱导性/边界 case** 才能暴露模型差异（本课 leading_refund 就是为此加的）。
5. **每 Phase 的实验都是单变量**：P2 护栏（recursion_limit/熔断/异常）逐项对照、P4 验证节点前后对照、本课 prompt 规则前后对照——同一纪律贯穿。

## 五、三问法精读指引

1. `judge_case` 判据为什么不用第二个 LLM 打分？（答：LLM 评判不可复现且贵；子串/工具名断言透明、可复跑、零成本——本课 3 次迭代改的就是这些断言的精度）
2. leading_refund case 为什么能拉开 V1/V2 差距而普通 case 不能？（答：普通问题模型本来就稳；诱导性问题制造"编造诱惑"，规则才显价值——**eval 集要设计能暴露差异的边界 case**）
3. 单变量回归的"V2 变好"如何保证不是随机？（答：同模型同温度、两版只差一句规则、同 7 case——但不能完全排除，所以写"单次实跑未挑选"、多跑几次看稳定）

# 示例语料（RAG 原理实验专用）

> 这是一份**故意做小**的语料：只有 6 段，每段一个主题。
> 小语料的好处是——你能一眼看完所有内容，从而看清「检索到底在干什么」。
> 真实项目里用的是 37 篇技术文档，但那份太大，反而不利于观察原理。

## 1. 设备定位

移动端会定期把设备位置上报到服务端，前端拿到的是 GPS 经纬度坐标。

## 2. 天气查询

查询某地天气需要先知道城市编码，再调用气象接口拿温度与降水。

## 3. 订单系统

订单号形如 SO-1003，客服工单需要按订单号做精确检索。

## 4. Agent 工具

create_agent 和 create_react_agent 是两个不同的构造函数，参数名不一样。

## 5. 数据备份

每天凌晨把数据库快照上传到对象存储，保留最近三十天。

## 6. 用户偏好

用户可以选择深色主题，偏好会写入本地存储，下次打开自动生效。

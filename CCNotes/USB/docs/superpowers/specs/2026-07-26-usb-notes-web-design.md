## 四、包结构图设计

### 4.1 渲染方式

DOM `<div>` 横向 flex 排列，每个字段宽度按 bit 数 `flex-grow` 等比缩放：

```
┌─────────┬─────────┬────────────┬──────────┬──────────┬────────┐
│  SYNC   │   PID   │    ADDR    │   ENDP   │   CRC5   │  EOP   │
│  8 bit  │  8 bit  │   7 bit    │  4 bit   │  5 bit   │ 3 bit  │
│00000001 │ IN=0x69 │ 0x01~0x7F  │ EP1=0001 │ 多项式   │ SE0+J  │
└─────────┴─────────┴────────────┴──────────┴──────────┴────────┘
  蓝        蓝         青          青          紫        灰
```

### 4.2 颜色编码（6 色固定体系）

| 角色 | 颜色 | 色值 | 暗色模式变体 |
|------|------|------|-------------|
| SYNC / PID | 蓝 | `#1e90ff` | `#8ab4f8` |
| 地址 / 端点 | 青 | `#20c997` | `#63e6be` |
| 数据字段 | 橙 | `#ffa94d` | `#ffc078` |
| 校验字段 | 紫 | `#845ef7` | `#b197fc` |
| 结束标记 | 灰 | `#adb5bd` | `#dee2e6` |
| Frame Number | 绿 | `#51cf66` | `#69db7c` |

### 4.3 交互

- **hover** 某字段 → tooltip 弹出详细解释
- 包图过宽时容器支持横向滚动，字段不折行不缩放
- 字段内文字始终可选中/复制

### 4.4 数据模型

```js
const PACKET = {
  id: 'token-packet',
  title: 'Token 包结构 (IN/OUT/SETUP)',
  totalBits: 35,
  fields: [
    { name: 'SYNC', bits: 8, desc: '同步序列 00000001, LSB first', color: 'sync' },
    { name: 'PID',  bits: 8, desc: '包标识符, 高4位=~低4位',     color: 'pid' },
    { name: 'ADDR', bits: 7, desc: '设备地址 0x01~0x7F',         color: 'addr' },
    { name: 'ENDP', bits: 4, desc: '端点号 0~15',                color: 'addr' },
    { name: 'CRC5', bits: 5, desc: '多项式 x⁵+x²+1, 校验 ADDR+ENDP', color: 'crc' },
    { name: 'EOP',  bits: 3, desc: 'SE0 2bit + J 1bit',         color: 'eop' },
  ]
};
```

## 五、架构流程图设计

### 5.1 渲染方式

纯手写内联 SVG，每张图直接嵌入对应知识卡片。

### 5.2 SVG 统一风格

- 线条：2px 圆角折线，色值 `#495057`
- 节点块：8px 圆角矩形，浅色填充 + 1px 深色边框
- 文字：13px sans-serif，深色
- 颜色复用包结构图的 6 色体系
- 无外部字体依赖

### 5.3 已规划的架构图清单
